# 試作（reference/prototype.html）と DESIGN.md の差分

マイルストーン 1 の着手時点で `reference/prototype.html` を読み、`docs/DESIGN.md` と突き合わせた結果。
「実装済み」は試作が設計どおりに動く項目、「挙動が違う」は設計と試作のどちらかを直す必要がある項目、
「未実装」は試作に無い項目。`core` への移植は「実装済み」「挙動が違う」の挙動をそのまま写す（試作準拠）。

## 移植時に決めたこと

- 試作の挙動と設計が食い違う箇所は、マイルストーン 1 では**試作準拠**で写す（「試作と同じ挙動」が完了条件のため）。
  設計に寄せる変更はマイルストーン 2 以降で `tuning.ts` の値や `tree.ts` の要求値を変えて行う。
- 「早すぎる入力の無視」「未入力の締切に基本許容幅を使う」の 2 点は設計に無い試作固有の挙動。
  設計側への追記か、試作側の修正かを決める必要がある。
