# UI の方向: サーカスの興行ポスターと切符

アートディレクター役のレビュー（利用者の指摘「ゲームというよりアプリ寄り」への回答）。ui / graphics の作業指示として使う。

## なぜ「アプリ」に見えるか

- 全画面がダッシュボードのグリッド。左「ゲーム」カードと右「サイド」カードが同じ角丸・罫線・影でベージュの平坦なページに並び、ゲーム画面がウィジェットに見える。下 1/4 は空のベージュ
- KPI タイル型の財布（アイコン + 太字数字 + ラベルの角丸ピル）
- ブラウザ風タブ（下線 2px と薄い背景差だけ。鍵は通知ドット）
- key: value の表組み（球数 / 1拍 / 許容幅）が設定画面と同じ
- ツリーがフォーム（見出し + 説明 + 右端に価格ボタンの横長カード、縦 1 列）。木に見えない
- 記録帳が通知一覧（緑チェック + 1 行テキスト × 6、下に KPI タイル）
- 書体が全部同じゴシック 1 種（同梱していないので実機ではシステム書体）
- ピル型ボタン（iOS / Material）
- 状態変化に演出が無い（見せ場でも右ペインは変わらない。完走はアイコンと文字だけ。トーストは OS 通知の形）
- 良い点: Canvas の中（主人公、球、拍の輪、判定文字、幕、客席）は既にゲーム。問題は Canvas の外

## 方向（1 本化）

「サーカスの興行ポスターと切符」。主人公は新人団員で、練習場 → 路上 → 舞台という興行に出るまでの物語。
ライト = 昼の紙、ダーク = 夜の楽屋（紺墨の紙に琥珀のインク）。

### 全体

- ページを「場」にする: body の背景を壁と床にし、左の Canvas は角丸・罫線・影を捨てて左端／上端にブリード。HUD は Canvas 下端に「板」として直付け（板は墨、数字は琥珀）。右ペインだけを「壁に貼ったポスター」にする
- フレーム: 右ペインは紙（薄い繊維ノイズ）。縁は二重罫線（太 2px + 細 1px、琥珀 → 墨）と四隅の角飾り、上端に画鋲かテープ。影は下方向 1 段。カード内カードをやめ、罫線 1 本 + 見出し帯か区切り線（波線・点線）。角丸は 2px 以下、ボタンだけ切符の角（斜め切り落とし）
- タイポグラフィ 3 段: 見出し・タブ・判定・完走 = 表示用日本語書体、数字 = 太いスラブセリフ（tabular-nums）、本文 = ゴシック。見出しは字間広め、系統名は帯に白抜き
- タブ → 切符（両端に半円の切欠き、ミシン目）。選択中は手前に浮いて琥珀、未選択は紙色で沈む、未解放は裏返し（灰 + 鍵）
- 財布 → 窓口の帯 1 本（墨地）に通貨をアイコン + スラブ体の数字で横並び。増加時に数字が跳ねる。アイコンは「物」（キャッチ = 手と球、クリーン = 星形の判子、コア = 金貨、拍手 = 手袋 2 つ、体得点 = リボン章）
- ボタン: 切符形か押印形（墨の太枠、白抜き、押すと 1px 沈む）。「投げ始める」だけ琥珀、他は墨線のゴースト
- トースト: 「幕間の看板」。紙色の札が上から紐で降りて揺れる。clean 連続・クリーン獲得・コア獲得で札の色を変える

### 画面ごと

- 練習場: Canvas ブリード + 板 HUD。パターン選択は「演目札」（縦長、上に紐穴）。仕様の表は「本日の稽古」ビラ 1 枚にまとめ、数字だけスラブ体で大きく。「あと N 拍で見せ場」は Canvas 上端の横断幕（コーラル地。graphics）
- 身体: 5 系統を「5 枚の張り紙」。各系統は横並びの判子ノード（押した分が琥珀インク）。体得は下段に鎖線でぶら下がる。価格は判子の右に札 1 つ。1280×800 で 2 列
- 記録帳: 「番付」形式。節目は達成順に大きな字 → 小さな字の縦の帯、達成は朱印。通算キャッチ／最長／回数は番付の頭に大きな数字。封印は帯紙を貼る見た目
- クラブ: 回転数の 3 枚札に「×1 ×2 ×3」を大きくスラブ体
- 路上: 右ペインを黒板の看板に。演目札に「見せた」の朱印。変換は投げ銭の帽子アイコン付き切符形。拍手時に客席の手が上がる 2 コマ（graphics）
- パッシング: 相方の札（顔）を上端に 1 枚、「パス 100%」は相方の吹き出し
- 舞台: 右ペインを深紅の紙に切替（`data-venue="stage"`）。「ショー 18/40 拍」は幕の上の電飾看板（graphics）
- 完走: トロフィーをやめ、主人公のお辞儀 + 客席の紙吹雪 + 幕が上がって照明（graphics）。右ペインは「千秋楽」ポスター（表示用書体で大きく、下に 5 つの記録）
- 設定: 楽屋の掲示。紙の縁と見出し帯、チェックボックスは判子形
- ダーク: 紙を紺墨に、罫線を琥珀のインクに。Canvas の壁色はライトと同系（夜の稽古場として暗く。graphics）

## 変えない点

- 拍の輪の仕組みと判定文字の位置。放物線が進行表示になっている点。ゲージを足さない
- 1280×800 で全情報が 1 画面に収まる密度。パディングは今の値以下
- ライト／ダーク両対応（CSS 変数）。紙の質感も変数で差し替える
- 文言は i18n 経由。英語のタブ名が切符に収まるかは英語表示で確認
- 主人公の手続き描画と pose.ts。素材差し替えは docs/CHARACTER.md の流れで
- 「動きを減らす」設定で横断幕・紙吹雪などは静止画に

## 書体（同梱。src/assets/fonts/、THIRD_PARTY_NOTICES.md に OFL 表記）

- 表示用（日本語）: 第 1 候補 Kaisei Decol（Bold）。第 2 候補 Yusei Magic
- 数字（欧文スラブ）: Alfa Slab One または Rowdies
- 本文: Zen Kaku Gothic New（Regular + Bold）を同梱するか、指定を外してシステム書体に
- サブセット: 文言は i18n に閉じているので、そこに出る文字 + 数字 + 記号 + かな全部で `pyftsubset --flavor=woff2` すれば 1 書体 150〜400 KB。i18n から文字集合を作るスクリプトを scripts/ に置く。合計 1 MB 前後
- 取得: fonts.gstatic.com から TTF を取れる（GitHub の raw は取れない）。`font-display: block`
