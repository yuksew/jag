# 試作と移植版の挙動比較手順

マイルストーン 1 の完了確認。`reference/prototype.html` と Electron 版を並べて、同じ操作で同じ結果になることを見る。

## 準備

```
pnpm install
pnpm dev                       # Electron 版（左）
# 別ウィンドウで reference/prototype.html をブラウザで開く（右）
```

試作は `localStorage['sankyu-proto']`、Electron 版は `userData/sankyu/save/save.json` に保存する。
両方とも「記録を消す」で初期状態にしてから始める。

- Windows: `%APPDATA%\sankyu\save\`
- macOS: `~/Library/Application Support/sankyu/save/`
- Linux: `~/.config/sankyu/save/`

## 自動チェック

```
pnpm compile && pnpm smoke     # Linux でヘッドレスなら xvfb-run -a pnpm smoke
```

起動 → Space で開始 → 拍に合わせて 6 回投げる → やめる → `save.json` と `save.json.bak` が書かれることを確認し、
スクリーンショット（boot / run / body）を一時ディレクトリに置く。`SMOKE_SHOTS=<dir>` で置き場所を指定できる。

## セーブの堅牢性（Electron 版のみ）

1. ラン終了後に `save/` を見る: `save.json` と `save.json.bak` がある（2 回目以降の書き込みで .bak ができる）
2. `save.json` を壊す（先頭を削るなど）→ 起動時に「前回のバックアップから復元しますか」→「復元する」で .bak の内容に戻る
3. `save.json` を消して `.bak` だけ残す → 同じダイアログが出る
4. 試作の `localStorage['sankyu-proto']` の JSON を `save.json` にそのまま貼る → version 無しでも読める（`migrate.ts` の v0 → v1）

## 試作と意図的に違う点

- キーのオートリピート（Space 長押し）を無視する。試作は連打扱いになる
- 文言は `src/i18n/ja.ts` から出す。表示内容は同じ
- ログを `userData/sankyu/logs/YYYY-MM-DD.log` に書く（未処理例外もここに出る）
- タイトルの副題が「ジャグリング・インクリメンタル」（試作は「〜試作」）
